# Support

## Where to ask

| What | Where |
|---|---|
| A bug, a crash, a wrong result | [Open an issue](https://github.com/victoryotzev/linkedin-mcp/issues) using the bug template |
| A feature idea | [Open an issue](https://github.com/victoryotzev/linkedin-mcp/issues) using the feature template |
| A security vulnerability | **Not an issue** — see [SECURITY.md](SECURITY.md) |
| A question about contributing | [CONTRIBUTING.md](CONTRIBUTING.md) first, then an issue |

## What to expect

One maintainer, working on this in his own time. Issues are read, and most get
a first reply within a week. Some will be closed as out of scope; that is not a
judgement on the question.

There is no SLA, no paid support tier, and no commercial offering.

## Out of scope

These are things this project genuinely cannot help with:

- **LinkedIn account problems.** Restricted accounts, login trouble, or content
  removal are between you and LinkedIn.
- **Getting LinkedIn API access granted.** The developer-portal flow is
  LinkedIn's; [docs/linkedin-app-setup.md](docs/linkedin-app-setup.md) records
  what the portal does, but nobody here can approve an application.
- **Regional availability.** LinkedIn issues Member Data Portability tokens
  only to members in the European Economic Area or Switzerland. That is not
  something this project can work around, and it will not grow a workaround —
  see [docs/known-limitations.md](docs/known-limitations.md).
- **Advice on what to post.** This tool checks whether a draft is backed by
  evidence you supplied. It has no opinion on strategy, and it contains no LLM.
